Risk modelling · Monte Carlo

OpenCRQ

How much could a cyber attack cost a company in a bad year? OpenCRQ turns a 20-question control assessment and a set of loss scenarios into an annual loss distribution: the expected loss, a 1-in-20-year loss and a 1-in-100-year loss. Click any figure and it traces back to dated public data or a named assumption.

  • 489 ms for 100,000 simulated years × 4 scenarios
  • Every figure traceable to source data or a named assumption
  • What-if on the same random draws, so the seed doesn't decide
  • 374 backend + 133 frontend tests passing
  • Python
  • FastAPI
  • NumPy
  • pgmpy
  • React
  • TypeScript
