The 30-second version

An AI platform MVP that earned its production budget.

At Allianz Global Investors I built the MVP of the Gen AI Hub, one portal for the company's AI services, and its first feature, "Chat with your data": upload a file and ask questions about it. My demo to stakeholders led to budget approval for production.

The problem

Lots of documents, scattered AI tools.

Getting answers out of company documents took time and technical skills, AI tools were popping up with no common entry point, and leadership wanted proof before investing more.

  • Anyone can question their files in plain language.
  • All AI services in one portal, with permissions.
  • Fits Allianz's Azure and security rules.

What I built

A portal, and a chat that reads your documents.

One portal

Governance, chat, text tools and private apps for teams like HR and Legal, all in one place.

Chat with your data

Attach a file and ask about it; GPT-4 answers from passages found in your document.

Chat settings

Pick the model, creativity and answer length, or add a custom prompt.

Auto titles

One click generates a title and summary so chats are easy to find later.

Your files, your call

Deleting a file removes it from both the database and the search index.

How it's built

Index once, then rewrite, retrieve and answer.

Uploaded files are split and indexed by Azure AI Search. For each question, one prompt writes a search query from the chat and a second answers from the results.

The hard parts

Enterprise RAG is more than a vector search.

01

Follow-up questions

"And the second part?" is a bad search query. The LLM first rewrites it using the chat history, then the search runs.

02

Prompt injection

User text and documents both end up in the prompt. Azure AI Content Safety checks every prompt and alerts the security team on an attack.

03

Cost

GPT-4 is expensive at scale. Users pick the model per chat and switch to a stronger one only when needed.
